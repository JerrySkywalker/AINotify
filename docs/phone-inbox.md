# Android 收件箱 v3

Android 手机端使用 Material 3。设备和设备组可多选，组内成员与单选设备取并集。AI 前端独立多选。两个筛选条件取交集，清空某个条件会显示该维度的全部消息。设备组在「设置 → 设备组」维护。筛选条件、设备组和当前文件夹按 Relay 地址保存在本机。

## 消息操作

- 左滑默认存档，右滑默认切换置顶。两个方向可独立设置为置顶、存档、移到回收站或无操作。
- 「设置 → 滑动操作」提供试滑样例。正式消息也可以从行菜单操作。存档和回收站中的消息可移回收件箱。
- Relay 配置 `AINOTIFY_INBOX_TOKEN` 后，将该令牌填入手机「收件箱或只读令牌」。置顶和文件夹变更会同步到使用同一 Relay 的手机。断网期间操作排队，重新接收时补传。琥珀色只用于显示待同步状态。
- 旧版 Relay 和只读令牌支持手机本地操作。使用可写令牌后，手机显示 Relay 的同步状态。本地设备组、筛选条件、界面偏好和只读模式的消息操作保存在各手机上。

## AI 前端与外观

采集端使用 `--frontend-id` 和 `--frontend-label` 为不同工具配置绑定来源。共用同一工具配置的前端可从各自的启动环境传递 `AINOTIFY_FRONTEND_ID` 和 `AINOTIFY_FRONTEND_LABEL`。旧事件按工具归入「未标记前端」。

手机可选择跟随系统、简体中文或 English。主题支持跟随系统、浅色、深石墨和 AMOLED 纯黑，并可独立选择青绿、蓝色或紫色强调色。

## 本地验收

从 AINotify 根目录运行 `scripts/local-ci.ps1`。手机验收覆盖设备组、独立筛选、左右滑、撤销、回收站恢复、Relay 同步和断网恢复，以及语言和主题。Wear OS 验收覆盖通知与回复预览。运行结果及截图保存在 `build/ci`。

当前 Windows 和 Linux 采集适配器是 Codex 与 Claude Code。可按 Relay 协议给其他具备完成事件的前端编写适配器。
